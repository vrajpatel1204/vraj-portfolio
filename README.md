# vraj-portfolio

Personal portfolio — v1. Arc-reactor inspired, zero build step.

```
index.html      markup + content
css/style.css   theme, layout, animations
js/main.js      boot sequence, typing, reveals, parallax, embers canvas
```

Run locally: open `index.html`, or `npx serve .`
